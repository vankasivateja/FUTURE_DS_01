
# FUTURE_DS_01 - Business Sales Performance Analytics

## Objective
Analyze business sales data to identify:
- Revenue trends
- Top-selling products
- High-value categories
- Regional performance

## Tools Used
- Python
- Pandas
- Matplotlib

## Files Included
- sales_data.csv
- Business_Sales_Report.docx
- sales_by_region.png
- sales_by_category.png

## Key Insights
1. Highest performing region: West
2. Highest revenue category: Electronics
3. Top-selling product: Notebook

## Recommendations
- Focus marketing efforts on high-performing regions.
- Increase inventory for top-selling products.
- Improve underperforming regions with targeted campaigns.
